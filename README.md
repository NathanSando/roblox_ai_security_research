# AI-Assisted Roblox Security

A research project exploring how AI can support Roblox administrators and developers by identifying suspicious player activity and reviewing scripts for potential security issues.

## Overview

The project combines two planned capabilities:

- **Player activity analysis:** Analyze statistics such as location and level to identify discrepancies and flag suspicious activity for administrator review.
- **Script security review:** Provide an integrated script viewer in Roblox that uses AI to identify potential security issues and generate feedback focused on the affected code.

## How It Works

### Player Activity Analysis

1. Collect relevant player statistics.
2. Analyze the data for inconsistencies or unusual patterns.
3. Flag potentially suspicious activity with an explanation.
4. Let administrators review findings and decide whether action is needed.

### Script Security Review

1. View a script through the integrated viewer.
2. Analyze the code for potential security issues.
3. Generate feedback explaining the issues and suggesting improvements.

## Research Goals

- Explore how effectively AI can identify suspicious activity from player statistics.
- Evaluate false positives and the usefulness of explanations for administrators.
- Assess the accuracy and relevance of AI-generated code security feedback.
- Investigate how these tools can fit into Roblox moderation and development workflows.

## Limitations

AI-generated findings may be inaccurate or incomplete. Unusual player behavior does not necessarily indicate cheating, and automated code review cannot guarantee that a script is secure.

Flags and recommendations are intended to support human review. They should not be treated as proof of misconduct or used as the sole basis for enforcement.

## Data and Privacy

The project aims to collect only the data needed for analysis and restrict access to authorized reviewers. Player data and scripts should be handled according to the experience’s privacy requirements and any AI service’s data-handling policies.

## Project Status

Early research and development. Features described above are planned and may change as the project evolves.
